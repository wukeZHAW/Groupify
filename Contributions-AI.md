# AI Contributions

## Zweck

AI-Tools werden in diesem Projekt als Unterstützung bei der Entwicklung eingesetzt.
Die Verantwortung für den Code und alle vorgenommenen Änderungen bleibt beim Entwickler.

## Einsatzbereiche

AI kann insbesondere verwendet werden für:

- Unterstützung bei der Code-Erstellung
- Refactoring und Verbesserung bestehender Strukturen
- Fehlersuche und Debugging
- Erstellung und Erweiterung von Tests
- Unterstützung bei Dokumentation
- Erklärung und Recherche technischer Konzepte

## Regeln für AI-Unterstützung

- AI-generierter Code wird vor der Übernahme überprüft und verstanden.
- Änderungen müssen zu den bestehenden Anforderungen und zur Architektur passen.
- Bestehende Funktionalität darf durch AI-generierte Änderungen nicht unbeabsichtigt verändert werden.
- Nach relevanten Änderungen werden die vorhandenen Tests ausgeführt.
- AI-Vorschläge werden nicht ungeprüft übernommen.
- Die endgültige Entscheidung über Änderungen liegt beim Entwickler.
- Sensible oder personenbezogene Daten werden nicht unnötig an externe AI-Dienste übermittelt.

## Qualitätssicherung

AI-generierte oder AI-unterstützte Änderungen unterliegen denselben Qualitätsanforderungen wie manuell erstellter Code.

Insbesondere werden:

1. Änderungen überprüft,
2. bestehende Tests ausgeführt,
3. Fehler korrigiert,
4. Änderungen nachvollziehbar über Git dokumentiert.

AI dient damit als Entwicklungswerkzeug und ersetzt nicht die fachliche Prüfung der Ergebnisse.
